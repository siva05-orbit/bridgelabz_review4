# Global University Ranking Intelligence System

## Project Overview
This project performs an analytical study on the QS World University Rankings 2025 dataset using Python data analysis and visualization libraries. The objective of this project is to generate meaningful insights regarding global university rankings, educational dominance by country, academic reputation, and overall university performance.

The project was implemented using:
- NumPy
- Pandas
- Matplotlib
- Seaborn

# Objectives

The main objectives of this project are:

- Analyze ranking distribution by country
- Identify top universities by region
- Determine countries dominating global education
- Study score trends across universities
- Compare rankings with academic reputation scores
- Find countries with the highest average university scores
- Generate ranking-based insights for students

---

# Dataset

Dataset Used:
`QS_World_University_Rankings_2025_Top_global_universities.csv`

The dataset contains information about:
- University rankings
- Countries and regions
- Academic reputation scores
- Employer reputation scores
- International faculty and student scores
- Sustainability scores
- Overall university scores

# Visualizations Created
